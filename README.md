## Technologies & architecture

Static applications: HTML5, CSS3, JavaScript, GitHub Pages. Advanced tools may require PHP, Python, databases, REST APIs or AI services on separate infrastructure. GitHub Pages does not execute server-side code. / Les outils avancés pourront nécessiter une infrastructure séparée.

## Installation & publication

Open `index.html` locally or serve the directory with `py -3 -m http.server 8000`. For GitHub Pages, upload the portal files to the root of `ADJAMS-IT-Lab/first-web-services`, commit to `main`, then select Settings → Pages → Deploy from a branch → main → / (root) → Save.

See [GitHub Pages setup / Guide de publication](GITHUB_SETUP.md).

## Privacy, limitations & licensing / Confidentialité, limites et licence

Do not upload credentials or private audit reports to public repositories. External websites may block iframe embedding. Visual testing is not device certification. Free access does not automatically grant an open-source license; licensing remains to be decided by the owner. / Ne publiez aucune donnée confidentielle. Les tests visuels ne constituent pas une certification. La licence reste à définir.
