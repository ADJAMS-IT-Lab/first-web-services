5. Git PUSH / PULL — Windows CMD

Installer Git for Windows. Cloner après le premier commit. Authentification GitHub requise pour pousser.

mkdir C:\FWS_Libs
cd /d C:\FWS_Libs
git clone https://github.com/ADJAMS-IT-Lab/seo-checker-online.git
cd seo-checker-online
git pull origin main

Modifier et tester localement. Examiner les fichiers avant le commit.

git status
git add .
git commit -m "Update SEO Checker V1.1"
git push origin main

Pour marquer la version initiale, sur le commit V1.0 correspondant (avant les changements V1.1) :

git tag -a v1.0.0 -m "SEO Checker Online V1.0"
git push origin v1.0.0

GitHub → Releases → Draft a new release → sélectionner le tag → joindre le ZIP → Publish release. En cas de conflit Git, résoudre le conflit avant de pousser, ne pas forcer le push.

6. Technical limits

HTML, CSS, JS, JSON, XML, CSV, images, vidéos et WebAssembly sont compatibles. PHP, MySQL et Python serveur nécessitent un autre environnement. CORS limite les analyses SEO externes : prévoir import HTML et copier-coller. Ne jamais publier de secrets ou clés API privées. Respecter les conditions et quotas GitHub Pages. Le score SEO interne n’est pas une note Google.
